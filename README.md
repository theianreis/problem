# Problem Solving — Rust, Python e C++

Repositório dedicado à prática de lógica de programação, algoritmos e resolução de problemas utilizando Rust, Python e C++. O objetivo é desenvolver o raciocínio computacional, explorar diferentes abordagens para solucionar problemas e consolidar os fundamentos da programação por meio de exercícios práticos.

## Objetivos

- Desenvolver habilidades de lógica de programação e pensamento computacional.
- Praticar estruturas de controle, loops, funções e coleções de dados.
- Resolver problemas utilizando diferentes linguagens de programação.
- Comparar abordagens e compreender as particularidades de cada linguagem.
- Registrar a evolução dos estudos por meio de exercícios e implementações.

## Como executar os códigos

Clone o repositório:

```bash
git clone https://github.com/theianreis/problem.git
```

Acesse a pasta do projeto:

```bash
cd problem
```

### Python

```bash
python arquivo.py
```

### Rust

Para executar um projeto configurado com Cargo:

```bash
cd rust
cargo run
```

### C++

Compile o arquivo utilizando um compilador compatível com C++:

```bash
g++ arquivo.cpp -o programa
./programa
```

Os comandos podem variar conforme a organização dos arquivos e o sistema operacional. Para Rust, o Cargo deve estar configurado caso seja utilizado o comando `cargo run`.
